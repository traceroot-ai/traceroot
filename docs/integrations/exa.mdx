Record what each [Exa](https://exa.ai) search costs next to your LLM spend. Every search becomes a tool span with its query, results, latency and dollar cost, and the cost counts toward the trace total.

<Note>
  traceroot does not auto-instrument Exa. You trace the search with `observe` and report its cost yourself, and traceroot stores the cost you report. See [Tool and API calls](/tracing/cost-tracking#tool-and-api-calls) for how reported costs add up.
</Note>

## Install

<Tabs>
  <Tab title="Python">
    ```bash
    pip install traceroot exa-py
    ```
  </Tab>
  <Tab title="TypeScript">
    ```bash
    npm install @traceroot-ai/traceroot exa-js
    ```
  </Tab>
</Tabs>

Reporting a cost requires `traceroot` 0.5.0 or later, or `@traceroot-ai/traceroot` 0.7.0 or later.

## Set up

Initialize traceroot once at startup. No integration flag is needed: the `observe` wrapper in the next step traces the search.

<Tabs>
  <Tab title="Python">
    ```python
    import traceroot

    traceroot.initialize()
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { TraceRoot } from '@traceroot-ai/traceroot';

    TraceRoot.initialize();
    ```
  </Tab>
</Tabs>

## Usage

Exa returns the dollar cost of each request in `costDollars`. To record it:

1. Wrap the search in a function traced as a tool span (`type="tool"`).
2. Read `costDollars.total` from the response.
3. Report it with `update_current_span(cost=...)` (`updateCurrentSpan` in TypeScript) while that span is open.

<Tabs>
  <Tab title="Python">
    ```python
    from exa_py import Exa
    from traceroot import observe, update_current_span

    exa = Exa()  # reads EXA_API_KEY

    @observe(name="exa_search", type="tool")
    def web_search(query: str):
        response = exa.search(query, num_results=3)
        if response.cost_dollars:
            update_current_span(cost=response.cost_dollars.total)
        return response
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import Exa from 'exa-js';
    import { observe, updateCurrentSpan } from '@traceroot-ai/traceroot';

    const exa = new Exa(process.env.EXA_API_KEY);

    async function webSearch(query: string) {
      return observe({ name: 'exa_search', type: 'tool' }, async (q: string) => {
        const response = await exa.search(q, { numResults: 3 });
        if (response.costDollars) updateCurrentSpan({ cost: response.costDollars.total });
        return response;
      }, query);
    }
    ```
  </Tab>
</Tabs>

Call `web_search` from your agent like any other function. Its span nests under the span that called it, and its cost adds to that trace's total.

## Verify

Run your code and confirm the trace arrives:
1. **In the traceroot UI**: Navigate to **Tracing > Traces** in [traceroot Cloud](https://app.traceroot.ai). You should see an `exa_search` span, at the root or under your agent's span. Open it to see its cost; the trace's total cost includes it.
2. **Via the CLI**: Run `traceroot traces list` to inspect your recent traces from the terminal.

## What gets captured

| Attribute | Description |
|-----------|-------------|
| Input | The query passed to `web_search` |
| Output | The search response |
| Cost | The `costDollars.total` you report, in USD |
| Latency | Request duration |

## Limitations

- A response without `costDollars` records no cost on the span.
