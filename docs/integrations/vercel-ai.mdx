Automatically capture agent runs, LLM calls, tool executions, and token usage from the [Vercel AI SDK](https://ai-sdk.dev) through its built-in OpenTelemetry support — no `instrumentModules` config required.

## Install

<Tabs>
  <Tab title="AI SDK 7">
    ```bash
    npm install @traceroot-ai/traceroot ai@^7 @ai-sdk/otel@^1 @ai-sdk/openai@^4 zod@^4
    ```
  </Tab>
  <Tab title="AI SDK 6 (legacy)">
    ```bash
    npm install @traceroot-ai/traceroot ai@^6 @ai-sdk/openai@^3 zod@^4
    ```
  </Tab>
</Tabs>

## Set up

<Tabs>
  <Tab title="AI SDK 7">
    Call `TraceRoot.initialize()` and register the AI SDK's OpenTelemetry integration before your first model call:

    ```typescript
    import { TraceRoot } from '@traceroot-ai/traceroot';
    import { registerTelemetry } from 'ai';
    import { OpenTelemetry } from '@ai-sdk/otel';

    TraceRoot.initialize();

    // Required on AI SDK 7 — without it, no spans are emitted.
    registerTelemetry(new OpenTelemetry({ usage: true }));
    ```
  </Tab>
  <Tab title="AI SDK 6 (legacy)">
    Call `TraceRoot.initialize()` before your first model call:

    ```typescript
    import { TraceRoot } from '@traceroot-ai/traceroot';

    TraceRoot.initialize();
    ```

    Then set `experimental_telemetry: { isEnabled: true }` on each call (see [Usage](#usage)).
  </Tab>
</Tabs>

## Usage

Once initialized, every `generateText` / `streamText` call, model call, and tool execution is captured automatically:

<Tabs>
  <Tab title="AI SDK 7">
    ```typescript
    import { TraceRoot } from '@traceroot-ai/traceroot';
    import { registerTelemetry, generateText, tool, isStepCount } from 'ai';
    import { OpenTelemetry } from '@ai-sdk/otel';
    import { openai } from '@ai-sdk/openai';
    import { z } from 'zod';

    TraceRoot.initialize();
    registerTelemetry(new OpenTelemetry({ usage: true }));

    // The agent run, both model calls, and the getWeather tool call are all traced.
    const result = await generateText({
      model: openai('gpt-4o-mini'),
      instructions: 'You are a concise weather assistant.',
      prompt: 'What is the weather in Tokyo?',
      stopWhen: isStepCount(5),
      telemetry: { functionId: 'weather_agent' },
      tools: {
        getWeather: tool({
          description: 'Get current weather for a city',
          inputSchema: z.object({ city: z.string() }),
          execute: async ({ city }) => ({ city, temp: 72, condition: 'sunny' }),
        }),
      },
    });

    console.log(result.text);
    await TraceRoot.flush();
    ```
  </Tab>
  <Tab title="AI SDK 6 (legacy)">
    ```typescript
    import { TraceRoot } from '@traceroot-ai/traceroot';
    import { generateText, tool, stepCountIs } from 'ai';
    import { openai } from '@ai-sdk/openai';
    import { z } from 'zod';

    TraceRoot.initialize();

    // The agent run, both model calls, and the getWeather tool call are all traced.
    const result = await generateText({
      model: openai('gpt-4o-mini'),
      system: 'You are a concise weather assistant.',
      prompt: 'What is the weather in Tokyo?',
      stopWhen: stepCountIs(5),
      // Required on every call in AI SDK 6.
      experimental_telemetry: { isEnabled: true, functionId: 'weather_agent' },
      tools: {
        getWeather: tool({
          description: 'Get current weather for a city',
          inputSchema: z.object({ city: z.string() }),
          execute: async ({ city }) => ({ city, temp: 72, condition: 'sunny' }),
        }),
      },
    });

    console.log(result.text);
    await TraceRoot.flush();
    ```
  </Tab>
</Tabs>

## Verify

Run your code and confirm the trace arrives:
1. **In the TraceRoot UI**: Navigate to **Tracing > Traces** in [TraceRoot Cloud](https://app.traceroot.ai). You should see a trace with root span `ai.generateText` (or your configured `functionId` such as `weather_agent`).
2. **Via the CLI**: Run `traceroot traces list` to inspect your recent traces from the terminal.

## What gets captured

| Attribute | Description |
|-----------|-------------|
| Model | The model passed to `generateText` / `streamText` / `ToolLoopAgent` |
| Messages | Input prompt and message history |
| Response | Generated text output |
| Tool calls | Each tool invocation with input and output |
| Tokens | Input and output token counts |
| Cost | Calculated from token usage and model pricing |
| Latency | Request duration per span |
| Multi-step iterations | Each step of a tool loop captured as a child span |

## Limitations

- AI SDK 7 requires Node >= 22.
- On AI SDK 6 (legacy), each model call must explicitly set `experimental_telemetry: { isEnabled: true }`.
