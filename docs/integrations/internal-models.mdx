traceroot Cloud provides the following models out of the box — no API key required.

## Anthropic

| Model               | Description                                            |
| ------------------- | ------------------------------------------------------ |
| `claude-opus-4-8`   | Most capable model for complex reasoning and debugging |
| `claude-opus-4-7`   | Previous Opus generation                               |
| `claude-opus-4-6`   | Earlier Opus generation                                |
| `claude-sonnet-5`   | Sonnet 5 for coding and agentic tasks                  |
| `claude-sonnet-5-5` | Adaptive thinking with a 1M-token context window       |
| `claude-sonnet-4-6` | Balanced performance and speed                         |
| `claude-opus-4-5`   | Earlier Opus generation                                |
| `claude-sonnet-4-5` | Previous Sonnet generation                             |
| `claude-haiku-5-5`  | Fast, low-cost; detector fallback without OpenAI key   |
| `claude-haiku-4-5`  | Fast and lightweight                                   |

## OpenAI

| Model           | Description                                       |
| --------------- | ------------------------------------------------- |
| `gpt-5.5`       | Default OpenAI model                              |
| `gpt-6-luna`    | Fast, low-cost GPT-6 model; the detector default  |
| `gpt-5.4`       | Balanced GPT-5.4 model                            |
| `gpt-5.4-mini`  | Fast and cost-efficient GPT-5.4 variant           |
| `gpt-5.4-nano`  | Smallest, lowest-cost GPT-5.4 variant             |
| `gpt-5`         | Previous flagship model                           |
| `gpt-5-mini`    | Fast and cost-efficient GPT-5 variant             |
| `o3`            | Advanced reasoning model                          |
| `gpt-5.3-codex` | Code-optimized model via Responses API            |
| `gpt-5.6-sol`   | GPT-5.6 for complex reasoning and tool use        |
| `gpt-5.6-terra` | Cost-efficient GPT-5.6 reasoning model            |
| `gpt-6-sol`     | GPT-6 for reasoning, coding, and tool use          |

## Bring Your Own Key (BYOK)

Need a model not listed here? With [BYOK](/ai-agent/byok) you can bring your own API key and use any supported provider — including Azure OpenAI, Google (Gemini), Amazon Bedrock, xAI, DeepSeek, OpenRouter, Kimi, GLM, and TypeSafe AI (detectors only).
