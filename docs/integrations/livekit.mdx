title: LiveKit Agents

Automatically capture voice agent sessions, conversational turns, Speech-to-Text (STT), LLM generations, Text-to-Speech (TTS), and tool executions from [LiveKit Agents](https://livekit.io) in Python and TypeScript.

TraceRoot ingests LiveKit Agents' OpenTelemetry spans and groups pipeline activity into structured agent sessions.

## Setup

<Tabs>
  <Tab title="Python">
    ```bash
    pip install traceroot livekit-agents
    ```

    Call `traceroot.initialize()` before starting your agent server:

    ```python
    import traceroot
    from traceroot import Integration

    traceroot.initialize(integrations=[Integration.LIVEKIT])
    ```
  </Tab>
  <Tab title="TypeScript">
    ```bash
    npm install @traceroot-ai/traceroot @livekit/agents zod
    ```

    Call `TraceRoot.initialize()` before defining or running your agent:

    ```typescript
    import * as livekitAgents from '@livekit/agents';
    import { TraceRoot } from '@traceroot-ai/traceroot';

    TraceRoot.initialize({
      instrumentModules: { livekitAgents },
    });
    ```
  </Tab>
</Tabs>

## Usage

<Tabs>
  <Tab title="Python">
    ```python
    from livekit.agents import Agent, AgentServer, AgentSession, JobContext, cli, function_tool
    import traceroot
    from traceroot import Integration, using_attributes

    class Assistant(Agent):
        def __init__(self) -> None:
            super().__init__(instructions="You are a helpful voice AI assistant.")

        @function_tool(description="Add two numbers.")
        async def add_numbers(self, a: float, b: float) -> str:
            return f"{a} + {b} = {a + b}"

    traceroot.initialize(integrations=[Integration.LIVEKIT])

    server = AgentServer()

    @server.rtc_session(agent_name="voice-assistant")
    async def entrypoint(ctx: JobContext) -> None:
        ctx.add_shutdown_callback(traceroot.flush_async)

        session = AgentSession(
            stt="deepgram/nova-3:en",
            llm="openai/chat-latest",
            tts="cartesia/sonic-3",
        )

        with using_attributes(session_id=ctx.room.name):
            await session.start(agent=Assistant(), room=ctx.room)
            await ctx.connect()

    if __name__ == "__main__":
        cli.run_app(server)
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import {
      Agent,
      AgentSession,
      defineAgent,
      tool,
      type JobContext,
    } from '@livekit/agents';
    import * as livekitAgents from '@livekit/agents';
    import { TraceRoot, usingAttributes } from '@traceroot-ai/traceroot';
    import { z } from 'zod';

    TraceRoot.initialize({
      instrumentModules: { livekitAgents },
    });

    const addNumbers = tool({
      name: 'add_numbers',
      description: 'Add two numbers.',
      parameters: z.object({
        a: z.number(),
        b: z.number(),
      }),
      execute: async ({ a, b }) => `${a} + ${b} = ${a + b}`,
    });

    export default defineAgent({
      entry: async (ctx: JobContext) => {
        ctx.addShutdownCallback(() => TraceRoot.flush());

        const session = new AgentSession({
          stt: 'deepgram/nova-3:en',
          llm: 'openai/chat-latest',
          tts: 'cartesia/sonic-3',
        });

        await usingAttributes({ sessionId: ctx.room.name }, async () => {
          await session.start({
            agent: new Agent({
              instructions: 'You are a helpful voice AI assistant.',
              tools: [addNumbers],
            }),
            room: ctx.room,
          });
          await ctx.connect();
        });
      },
    });
    ```
  </Tab>
</Tabs>

## What Gets Captured

| Attribute | Description |
|-----------|-------------|
| **Voice Sessions** | Groups all audio turns under the LiveKit room session identifier |
| **Agent Turns** | Each user speech utterance and agent response cycle |
| **STT / LLM / TTS** | Speech-to-text transcriptions, LLM generation spans, and audio synthesis metrics |
| **Tool Calls** | Function tools executed by the model with inputs, return values, and errors |
| **Token Usage** | LLM prompt and completion token counts |
