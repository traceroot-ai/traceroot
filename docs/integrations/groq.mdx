Automatically capture all Groq chat completion calls, including tool/function calls.

TraceRoot instruments the native [`groq`](https://pypi.org/project/groq/) SDK directly via `Integration.GROQ`.

## Install

```bash
pip install traceroot groq
```

## Set up

<Tabs>
  <Tab title="Python">
    ```python
    import traceroot
    from traceroot import Integration

    traceroot.initialize(integrations=[Integration.GROQ])
    ```
  </Tab>
</Tabs>

## Usage

Once initialized, all Groq completions are captured automatically:

```python
import os
from groq import Groq

client = Groq(api_key=os.environ["GROQ_API_KEY"])

# This call is automatically traced
response = client.chat.completions.create(
    model="llama-3.3-70b-versatile",
    messages=[
        {"role": "user", "content": "What is the capital of France?"},
    ],
)

print(response.choices[0].message.content)
```

## Verify

Run your code and confirm the trace arrives:
1. **In the TraceRoot UI**: Navigate to **Tracing > Traces** in [TraceRoot Cloud](https://app.traceroot.ai). You should see a trace with root span `Completions` (or `AsyncCompletions` when using `AsyncGroq`).
2. **Via the CLI**: Run `traceroot traces list` to inspect your recent traces from the terminal.

## What gets captured

| Attribute  | Description                                                       |
| ---------- | ----------------------------------------------------------------- |
| Model      | `llama-3.3-70b-versatile`, `llama-3.1-8b-instant`, etc.           |
| Messages   | Input messages array                                              |
| Response   | Completion content                                                |
| Tool calls | Function and tool call inputs, outputs, and status                |
| Tokens     | Prompt, completion, and total tokens                              |
| Latency    | Request duration                                                  |

## Limitations

- Groq auto-instrumentation currently does not support streaming responses.
