Record what each [TinyFish](https://tinyfish.ai) remote browser session costs next to your LLM spend. Every session becomes a tool span with its URL, result, duration and dollar cost, and the cost counts toward the trace total.

<Note>
  traceroot does not auto-instrument TinyFish and does not know your rate. You trace the session with `observe` and report its cost yourself, and traceroot stores the cost you report. See [Tool and API calls](/tracing/cost-tracking#tool-and-api-calls) for how reported costs add up.
</Note>

Reporting a cost requires `traceroot` 0.5.0 or later, or `@traceroot-ai/traceroot` 0.7.0 or later.

## Set up

Initialize traceroot once at startup. No integration flag is needed: the `observe` wrapper in the next step traces the session.

<Tabs>
  <Tab title="Python">
    ```python

    traceroot.initialize()
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { TraceRoot } from '@traceroot-ai/traceroot';

    TraceRoot.initialize();
    ```
  </Tab>
</Tabs>

## Usage

TinyFish bills remote browsers by the minute and returns no price, so you estimate the cost from the session's length. To record it:

1. Wrap the session in a function traced as a tool span (`type="tool"`).
2. Time the session from creation to close.
3. Multiply the minutes by your price per minute and report it with `update_current_span(cost=...)` (`updateCurrentSpan` in TypeScript) before the span closes. A `finally` block reports it even when the session fails.

<Tabs>
  <Tab title="Python">
    ```python
    import os
    import time

    import httpx
    from traceroot import observe, update_current_span

    PRICE_PER_MINUTE = 0.002  # your price per browser minute
    API = "https://api.browser.tinyfish.ai"
    HEADERS = {"X-API-Key": os.environ["TINYFISH_API_KEY"]}

    @observe(name="tinyfish_open_page", type="tool")
    def browse(url: str):
        start = time.monotonic()
        session = httpx.post(API, headers=HEADERS, json={"url": url}, timeout=60).json()
        try:
            ...  # drive the browser through session["cdp_url"]
        finally:
            minutes = (time.monotonic() - start) / 60
            update_current_span(cost=minutes * PRICE_PER_MINUTE)
            httpx.delete(f"{API}/{session['session_id']}", headers=HEADERS)
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { observe, updateCurrentSpan } from '@traceroot-ai/traceroot';

    const PRICE_PER_MINUTE = 0.002; // your price per browser minute
    const API = 'https://api.browser.tinyfish.ai';
    const headers = { 'X-API-Key': process.env.TINYFISH_API_KEY!, 'Content-Type': 'application/json' };

    async function browse(url: string) {
      return observe({ name: 'tinyfish_open_page', type: 'tool' }, async (u: string) => {
        const start = performance.now();
        const session = await (await fetch(API, { method: 'POST', headers, body: JSON.stringify({ url: u }) })).json();
        try {
          // drive the browser through session.cdp_url
        } finally {
          const minutes = (performance.now() - start) / 60000;
          updateCurrentSpan({ cost: minutes * PRICE_PER_MINUTE });
          await fetch(`${API}/${session.session_id}`, { method: 'DELETE', headers });
        }
      }, url);
    }
    ```
  </Tab>
</Tabs>

Call `browse` from your agent like any other function. Its span nests under the span that called it, and its cost adds to that trace's total.

## Verify

Run your code and confirm the trace arrives:
1. **In the traceroot UI**: Navigate to **Tracing > Traces** in [traceroot Cloud](https://app.traceroot.ai). You should see a `tinyfish_open_page` span, at the root or under your agent's span. Open it to see its cost; the trace's total cost includes it.
2. **Via the CLI**: Run `traceroot traces list` to inspect your recent traces from the terminal.

## What gets captured

| Attribute | Description |
|-----------|-------------|
| Input | The URL passed to `browse` |
| Output | The function's return value |
| Cost | Session minutes × your price per minute, in USD |
| Latency | Session duration |

## Limitations

- The cost is an estimate: TinyFish bills from its own usage records, which can run a little longer.
