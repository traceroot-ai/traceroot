Automatically capture agent runs, tool executions, and the underlying Gemini calls within the [Google Agent Development Kit (ADK)](https://github.com/google/adk-python).

## Setup

<Tabs>
  <Tab title="Python">
    ```python
    import traceroot
    from traceroot import Integration

    traceroot.initialize(integrations=[Integration.GOOGLE_ADK])
    ```
  </Tab>
</Tabs>

## Usage

Once initialized, ADK agent runs, tool calls, and Gemini calls are captured automatically:

```python
import asyncio
import traceroot
from traceroot import Integration
from google.adk import Agent
from google.adk.runners import InMemoryRunner
from google.genai import types

traceroot.initialize(integrations=[Integration.GOOGLE_ADK])


def get_weather(city: str) -> dict:
    """Get current weather for a city."""
    return {"status": "success", "city": city, "temp": 72, "condition": "sunny"}


# ADK resolves the Gemini API key from GOOGLE_API_KEY in the environment.
agent = Agent(
    name="assistant",
    model="gemini-3.8-flash",
    description="Helpful assistant with access to tools.",
    instruction="You are a helpful AI assistant. Use tools when needed.",
    tools=[get_weather],
)


async def main():
    runner = InMemoryRunner(agent=agent, app_name="traceroot-adk-demo")
    await runner.session_service.create_session(
        app_name="traceroot-adk-demo",
        user_id="demo-user",
        session_id="demo-session",
    )

    # The full run, including tool calls and Gemini calls, is traced
    async for event in runner.run_async(
        user_id="demo-user",
        session_id="demo-session",
        new_message=types.Content(
            role="user",
            parts=[types.Part(text="What's the weather in Tokyo?")],
        ),
    ):
        if event.is_final_response() and event.content and event.content.parts:
            print(event.content.parts[0].text)


if __name__ == "__main__":
    asyncio.run(main())
    traceroot.flush()
```

## Usage with the ADK CLI

If you run your agent with `adk run` or `adk web`, initialize TraceRoot at the top of `agent.py`, **before** the ADK imports:

```python
# my_agent/agent.py
import traceroot
from traceroot import Integration

traceroot.initialize(integrations=[Integration.GOOGLE_ADK])

from google.adk import Agent


def get_current_time(city: str) -> dict:
    """Returns the current time in a specified city."""
    return {"status": "success", "city": city, "time": "10:30 AM"}


root_agent = Agent(
    model="gemini-3.8-flash",
    name="root_agent",
    description="Tells the current time in a specified city.",
    instruction="Use the 'get_current_time' tool to answer.",
    tools=[get_current_time],
)
```

<Note>
  `adk web` and `adk api_server` install their own OpenTelemetry tracer provider before `agent.py` loads, so `@observe` spans are dropped in these modes; ADK's spans still arrive. Use `adk run` or your own runner to trace `@observe` functions.
</Note>

## What Gets Captured

| Attribute | Description |
|-----------|-------------|
| Runner calls | An `invocation [<app>]` chain span per runner call |
| Agent runs | An `agent_run [<agent>]` agent span per agent and sub-agent run |
| LLM calls | A `call_llm` span per Gemini call with model, request, and response |
| Tool calls | An `execute_tool <tool>` span per tool call with input arguments and result |
| Tokens & Cost | Input, output, and reasoning token counts per LLM call; cost for models in the pricing table, including `gemini-3.8-flash` |
| Sessions & users | The ADK session id as `session.id` and user id as `user.id` on every span |
| Latency | Duration per agent run and per span |

Model aliases such as `gemini-flash-latest` are not priced; pin a model id to get cost. In an ADK 2.x `Workflow`, only `Agent` nodes are captured today; function nodes are not yet traced.
