自动采集所有 Anthropic Messages API 调用。

## 安装

<Tabs>
  <Tab title="Python">
    ```bash
    pip install traceroot anthropic
    ```
  </Tab>
  <Tab title="TypeScript">
    ```bash
    npm install @traceroot-ai/traceroot @anthropic-ai/sdk
    ```
  </Tab>
</Tabs>

## 设置

<Tabs>
  <Tab title="Python">
    ```python
    import traceroot
    from traceroot import Integration

    traceroot.initialize(integrations=[Integration.ANTHROPIC])
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import Anthropic from '@anthropic-ai/sdk';
    import * as anthropicSDK from '@anthropic-ai/sdk';
    import { TraceRoot } from '@traceroot-ai/traceroot';

    TraceRoot.initialize({ instrumentModules: { anthropic: anthropicSDK } });

    const client = new Anthropic();
    ```
  </Tab>
</Tabs>

## 使用

初始化之后，所有 Anthropic 调用都会被自动采集：

<Tabs>
  <Tab title="Python">
    ```python
    import anthropic

    client = anthropic.Anthropic()

    # 这次调用会被自动追踪
    response = client.messages.create(
        model="claude-sonnet-4-20250514",
        max_tokens=1024,
        messages=[
            {"role": "user", "content": "What is the capital of France?"},
        ],
    )

    print(response.content[0].text)
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import Anthropic from '@anthropic-ai/sdk';

    const client = new Anthropic();

    // 这次调用会被自动追踪
    const response = await client.messages.create({
      model: 'claude-sonnet-4-20250514',
      max_tokens: 1024,
      messages: [
        { role: 'user', content: 'What is the capital of France?' },
      ],
    });

    console.log(response.content[0].text);
    ```
  </Tab>
</Tabs>

## 验证

运行你的代码，确认 trace 已经到达：
1. **在 traceroot 界面中**：进入 [traceroot Cloud](https://app.traceroot.ai) 的 **Tracing > Traces**。你会看到一条根 span 为 `messages.create` 的 trace（TypeScript 下是 `Anthropic Messages`）。
2. **通过 CLI**：运行 `traceroot traces list`，在终端里查看最近的 trace。

## 采集的内容

| 属性 | 说明 |
|---|---|
| 模型 | `claude-sonnet-4-20250514`、`claude-haiku-4-5-20251001` 等 |
| 消息 | 输入的消息数组 |
| 响应 | completion 内容 |
| Token | 输入和输出 token |
| 成本 | model ID 匹配 traceroot 价格表时计算得出 |
| 延迟 | 请求耗时 |
