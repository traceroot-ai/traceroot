把每次 [TinyFish](https://tinyfish.ai) 远程浏览器会话的成本和 LLM 开销记录在一起。每次会话都会成为一个工具 span，带有 URL、结果、时长和美元成本，这笔成本会计入 trace 的总成本。

<Note>
  traceroot 不会自动插桩 TinyFish，也不知道你的费率。你需要用 `observe` 追踪这次会话并自己上报成本，traceroot 保存的就是你上报的成本。上报的成本如何累加，请看[工具和 API 调用](/zh/tracing/cost-tracking#工具和-api-调用)。
</Note>

## 安装

<Tabs>
  <Tab title="Python">
    ```bash
    pip install traceroot httpx
    ```
  </Tab>
  <Tab title="TypeScript">
    ```bash
    npm install @traceroot-ai/traceroot
    ```
  </Tab>
</Tabs>

上报成本需要 `traceroot` 0.5.0 或更高版本，或 `@traceroot-ai/traceroot` 0.7.0 或更高版本。

## 设置

在启动时初始化一次 traceroot。不需要任何集成参数：下一步里的 `observe` 包装会追踪这次会话。

<Tabs>
  <Tab title="Python">
    ```python
    import traceroot

    traceroot.initialize()
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { TraceRoot } from '@traceroot-ai/traceroot';

    TraceRoot.initialize();
    ```
  </Tab>
</Tabs>

## 使用

TinyFish 的远程浏览器按分钟计费，并且不返回价格，所以你需要根据会话时长估算成本。记录它的步骤：

1. 把会话包在一个函数里，并把这个函数追踪为工具 span（`type="tool"`）。
2. 给会话计时，从创建到关闭。
3. 用分钟数乘以你的每分钟价格，在 span 结束之前用 `update_current_span(cost=...)`（TypeScript 里是 `updateCurrentSpan`）上报。放在 `finally` 代码块里，会话失败时也会上报。

<Tabs>
  <Tab title="Python">
    ```python
    import os
    import time

    import httpx
    from traceroot import observe, update_current_span

    PRICE_PER_MINUTE = 0.002  # 你的浏览器每分钟价格
    API = "https://api.browser.tinyfish.ai"
    HEADERS = {"X-API-Key": os.environ["TINYFISH_API_KEY"]}

    @observe(name="tinyfish_open_page", type="tool")
    def browse(url: str):
        start = time.monotonic()
        response = httpx.post(API, headers=HEADERS, json={"url": url}, timeout=60)
        response.raise_for_status()
        session = response.json()
        try:
            ...  # 通过 session["cdp_url"] 操控浏览器
        finally:
            minutes = (time.monotonic() - start) / 60
            update_current_span(cost=minutes * PRICE_PER_MINUTE)
            httpx.delete(f"{API}/{session['session_id']}", headers=HEADERS)
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { observe, updateCurrentSpan } from '@traceroot-ai/traceroot';

    const PRICE_PER_MINUTE = 0.002; // 你的浏览器每分钟价格
    const API = 'https://api.browser.tinyfish.ai';
    const headers = { 'X-API-Key': process.env.TINYFISH_API_KEY!, 'Content-Type': 'application/json' };

    async function browse(url: string) {
      return observe({ name: 'tinyfish_open_page', type: 'tool' }, async (u: string) => {
        const start = performance.now();
        const created = await fetch(API, { method: 'POST', headers, body: JSON.stringify({ url: u }) });
        if (!created.ok) throw new Error(`TinyFish session failed: ${created.status}`);
        const session = await created.json();
        try {
          // 通过 session.cdp_url 操控浏览器
        } finally {
          const minutes = (performance.now() - start) / 60000;
          updateCurrentSpan({ cost: minutes * PRICE_PER_MINUTE });
          await fetch(`${API}/${session.session_id}`, { method: 'DELETE', headers });
        }
      }, url);
    }
    ```
  </Tab>
</Tabs>

像调用其他函数一样，在 agent 里调用 `browse`。它的 span 会嵌套在调用它的 span 下面，它的成本会计入这条 trace 的总成本。

## 验证

运行你的代码，确认 trace 已经到达：
1. **在 traceroot 界面中**：进入 [traceroot Cloud](https://app.traceroot.ai) 的 **Tracing > Traces**。你会看到一个 `tinyfish_open_page` span，位于根部或你的 agent 的 span 下面。打开它可以看到成本，trace 的总成本里包含这笔成本。
2. **通过 CLI**：运行 `traceroot traces list`，在终端里查看最近的 trace。

## 采集的内容

| 属性 | 说明 |
|-----------|-------------|
| 输入 | 传给 `browse` 的 URL |
| 输出 | `browse` 的返回值，例如页面标题 |
| 成本 | 会话分钟数 × 你的每分钟价格，单位是美元 |
| 延迟 | 会话时长 |

## 限制

- 成本是估算值：TinyFish 按它自己的用量记录计费，时长可能略长一些。
