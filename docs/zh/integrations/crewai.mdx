自动采集 CrewAI 框架里的 agent 角色、任务、crew 执行和工具调用。

## 安装

<Tabs>
  <Tab title="Python">
    ```bash
    pip install traceroot crewai
    ```
  </Tab>
</Tabs>

## 设置

<Tabs>
  <Tab title="Python">
    ```python
    import traceroot
    from traceroot import Integration

    traceroot.initialize(integrations=[Integration.CREWAI, Integration.OPENAI])
    ```
  </Tab>
</Tabs>

## 使用

初始化之后，crew 和 agent 的执行都会被自动采集：

```python
from crewai import Agent, Task, Crew

researcher = Agent(
    role="Research Analyst",
    goal="Uncover the latest developments in AI agent frameworks",
    backstory="You are an expert at identifying emerging trends in AI.",
)

writer = Agent(
    role="Tech Writer",
    goal="Craft a compelling summary of AI agent framework trends",
    backstory="You turn complex technical insights into engaging narratives.",
)

research_task = Task(
    description="Analyze the latest AI agent frameworks and summarize key trends.",
    expected_output="A concise research summary",
    agent=researcher,
)

write_task = Task(
    description="Write a short article based on the research summary.",
    expected_output="A short article on AI agent framework trends",
    agent=writer,
    context=[research_task],
)

crew = Crew(agents=[researcher, writer], tasks=[research_task, write_task])

# 整个 crew 执行都会被自动追踪
result = crew.kickoff()
```

## 验证

运行你的代码，确认 trace 已经到达：
1. **在 traceroot 界面中**：进入 [traceroot Cloud](https://app.traceroot.ai) 的 **Tracing > Traces**。你会看到一条根 span 为 `Crew_<id>.kickoff` 的 trace。如果用 `Crew(name=...)` 给 crew 命了名，根 span 会用这个名字。
2. **通过 CLI**：运行 `traceroot traces list`，在终端里查看最近的 trace。

## 采集的内容

| 属性 | 说明 |
|-----------|-------------|
| crew 执行 | 最外层的 `kickoff()` 会话 |
| agent 角色 | 每个 agent 的 role、goal 和 backstory，作为 span 元数据 |
| 任务步骤 | 每一次任务执行，包含输入和输出 |
| 工具调用 | 工具调用，包含输入参数和结果 |
| LLM 调用 | 发给提供商的原始 completion 请求 |
| 委派层级 | manager 和 agent 的关系，以及任务分配 |
| token 用量 | 汇总所有 LLM 调用 |
| 成本 | 底层模型 ID 能匹配 traceroot 的价格表时汇总计算 |

## 限制

- CrewAI 把 LLM 生成交给底层提供商（例如 OpenAI、Anthropic）。建议在初始化 CrewAI 的同时初始化提供商的集成（例如 `Integration.OPENAI`），这样 token 用量和成本才算得准。
