title: Notte
description: 把 Notte 浏览器会话的成本记录到对应的工具 span 上
---

把每次 [Notte](https://www.notte.cc) 云端浏览器会话的成本和 LLM 开销记录在一起。每次会话都会成为一个工具 span，带有 URL、抓取到的页面、时长和美元成本，这笔成本会计入 trace 的总成本。

<Note>
  traceroot 不会自动插桩 Notte。你需要用 `observe` 追踪这次会话并自己上报成本，traceroot 保存的就是你上报的成本。上报的成本如何累加，请看[工具和 API 调用](/zh/tracing/cost-tracking#工具和-api-调用)。
</Note>

## 安装

<Tabs>
  <Tab title="Python">
    ```bash
    pip install traceroot notte-sdk
    ```
  </Tab>
  <Tab title="TypeScript">
    ```bash
    npm install @traceroot-ai/traceroot notte-sdk
    ```
  </Tab>
</Tabs>

上报成本需要 `traceroot` 0.5.0 或更高版本，或 `@traceroot-ai/traceroot` 0.7.0 或更高版本。

## 设置

在启动时初始化一次 traceroot。不需要任何集成参数：下一步里的 `observe` 包装会追踪这次会话。

<Tabs>
  <Tab title="Python">
    ```python
    import traceroot

    traceroot.initialize()
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { TraceRoot } from '@traceroot-ai/traceroot';

    TraceRoot.initialize();
    ```
  </Tab>
</Tabs>

## 使用

Notte 的云端浏览器会话按小时计费，并且不返回单次会话的价格，所以你需要根据会话时长估算成本。记录它的步骤：

1. 把会话包在一个函数里，并把这个函数追踪为工具 span（`type="tool"`）。
2. 给会话计时，从启动到停止。
3. 用小时数乘以每小时费率，在 span 结束之前用 `update_current_span(cost=...)`（TypeScript 里是 `updateCurrentSpan`）上报。放在 `finally` 代码块里，会话失败时也会上报。

<Tabs>
  <Tab title="Python">
    ```python
    import time

    from notte_sdk import NotteClient
    from traceroot import observe, update_current_span

    PRICE_PER_HOUR = 0.01  # Notte 的浏览器会话费率

    client = NotteClient()  # 读取 NOTTE_API_KEY

    @observe(name="browse", type="tool")
    def browse(url: str):
        start = time.monotonic()
        try:
            with client.Session() as session:
                session.execute(type="goto", url=url)
                return session.scrape(only_main_content=True)
        finally:
            hours = (time.monotonic() - start) / 3600
            update_current_span(cost=hours * PRICE_PER_HOUR)
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { NotteClient } from 'notte-sdk';
    import { observe, updateCurrentSpan } from '@traceroot-ai/traceroot';

    const PRICE_PER_HOUR = 0.01; // Notte 的浏览器会话费率

    const client = new NotteClient(); // 读取 NOTTE_API_KEY

    async function browse(url: string) {
      return observe({ name: 'browse', type: 'tool' }, async (u: string) => {
        const start = performance.now();
        const session = client.Session();
        await session.start();
        try {
          await session.execute({ type: 'goto', url: u });
          return await session.scrape();
        } finally {
          await session.stop();
          const hours = (performance.now() - start) / 3_600_000;
          updateCurrentSpan({ cost: hours * PRICE_PER_HOUR });
        }
      }, url);
    }
    ```
  </Tab>
</Tabs>

像调用其他函数一样，在 agent 里调用 `browse`。它的 span 会嵌套在调用它的 span 下面，它的成本会计入这条 trace 的总成本。

## 验证

运行你的代码，确认 trace 已经到达：
1. **在 traceroot 界面中**：进入 [traceroot Cloud](https://app.traceroot.ai) 的 **Tracing > Traces**。你会看到一个 `browse` span，位于根部或你的 agent 的 span 下面。打开它可以看到成本，trace 的总成本里包含这笔成本。
2. **通过 CLI**：运行 `traceroot traces list`，在终端里查看最近的 trace。

## 采集的内容

| 属性 | 说明 |
|-----------|-------------|
| 输入 | 传给 `browse` 的 URL |
| 输出 | 抓取到的页面内容 |
| 成本 | 会话小时数 × 每小时费率，单位是美元 |
| 延迟 | 会话时长 |

## 限制

- 成本是估算值：Notte 会按它自己的计费规则对会话时长取整。
- 住宅代理流量和 LLM token 单独计费，不包含在内。
