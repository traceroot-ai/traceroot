[Microsoft Agent Framework](https://github.com/microsoft/agent-framework) 内置了 OpenTelemetry 输出，traceroot 借助它自动采集 agent 运行、模型调用和工具执行，不需要手动给框架插桩。

## 安装

<Tabs>
  <Tab title="Python">
    ```bash
    pip install "traceroot[agent-framework]" agent-framework-openai
    ```
  </Tab>
</Tabs>

## 设置

<Tabs>
  <Tab title="Python">
    ```python
    import traceroot
    from traceroot import Integration

    traceroot.initialize(integrations=[Integration.AGENT_FRAMEWORK])
    ```
  </Tab>
</Tabs>

请在导入 `agent_framework` **之前**初始化 traceroot，这样 OpenTelemetry 插桩会在框架发出第一个 span 之前就接好。

## 使用

初始化之后，每次 agent 调用、模型调用和工具执行都会被自动采集：

```python
import asyncio

import traceroot
from traceroot import Integration

traceroot.initialize(integrations=[Integration.AGENT_FRAMEWORK])

# 在 initialize() 之后导入，这样追踪已经生效。
from agent_framework import Agent
from agent_framework.openai import OpenAIChatClient


def get_weather(city: str) -> str:
    """Return a short weather forecast for a city."""
    return f"{city}: 18°C, partly cloudy."


agent = Agent(
    OpenAIChatClient(model="gpt-4o-mini"),
    "You are a helpful travel concierge. Use the weather tool when relevant.",
    name="Concierge",
    tools=[get_weather],
)


async def main():
    # agent 运行、模型调用和 get_weather 工具调用都会被追踪。
    response = await agent.run("What's the weather in Tokyo?")
    print(response.text)


asyncio.run(main())
```

工具就是普通函数。Agent Framework 已经会为每次调用发出一个 `execute_tool` span，所以不需要手动加装饰器。

## 验证

运行你的代码，确认 trace 已经到达：
1. **在 traceroot 界面中**：进入 [traceroot Cloud](https://app.traceroot.ai) 的 **Tracing > Traces**。你会看到一条根 span 为 `invoke_agent Concierge` 的 trace，Agent Framework 会把每个 agent span 命名为 `invoke_agent <agent name>`。
2. **通过 CLI**：运行 `traceroot traces list`，在终端里查看最近的 trace。

## 采集的内容

| 属性 | 说明 |
|-----------|-------------|
| Agent 运行 | 每次 agent 调用记录为一个 span（被委派的 agent 会嵌套显示） |
| 模型 | 每次调用使用的对话模型 |
| 工具调用 | 每次工具执行对应一个 `execute_tool` span，包含参数 |
| 响应 | 生成的文本和工具输出 |
| Token | 输入和输出 token 数 |
| 成本 | model ID 匹配 traceroot 价格表时计算 |
| 延迟 | 请求耗时 |

## 限制

- 需要通过 `pip install "traceroot[agent-framework]"` 安装 `agent-framework` extra。
- 必须在导入 `agent_framework` 之前初始化 traceroot，这样 OpenTelemetry 监听器会在 span 生成之前挂好。需要 OpenTelemetry >= 1.39。
