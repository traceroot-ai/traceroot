把每次 [Tavily](https://tavily.com) 搜索的成本和 LLM 开销记录在一起。每次搜索都会成为一个工具 span，带有查询、结果、延迟和美元成本，这笔成本会计入 trace 的总成本。

<Note>
  traceroot 不会自动插桩 Tavily，也不知道你的套餐价格。你需要用 `observe` 追踪这次搜索并自己上报成本，traceroot 保存的就是你上报的成本。上报的成本如何累加，请看[工具和 API 调用](/zh/tracing/cost-tracking#工具和-api-调用)。
</Note>

## 安装

<Tabs>
  <Tab title="Python">
    ```bash
    pip install traceroot tavily-python
    ```
  </Tab>
  <Tab title="TypeScript">
    ```bash
    npm install @traceroot-ai/traceroot @tavily/core
    ```
  </Tab>
</Tabs>

上报成本需要 `traceroot` 0.5.0 或更高版本，或 `@traceroot-ai/traceroot` 0.7.0 或更高版本。

## 设置

在启动时初始化一次 traceroot。不需要任何集成参数：下一步里的 `observe` 包装会追踪这次搜索。

<Tabs>
  <Tab title="Python">
    ```python
    import traceroot

    traceroot.initialize()
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { TraceRoot } from '@traceroot-ai/traceroot';

    TraceRoot.initialize();
    ```
  </Tab>
</Tabs>

## 使用

Tavily 按 credit 计费，每个 credit 值多少美元取决于你的套餐。在你请求 usage 信息时，它会返回一次搜索消耗的 credit 数。记录成本的步骤：

1. 把搜索包在一个函数里，并把这个函数追踪为工具 span（`type="tool"`）。
2. 用 `include_usage=True`（TypeScript 里是 `includeUsage: true`）请求 usage 信息，并读取消耗的 credit 数。
3. 乘以你的每 credit 价格，趁这个 span 还没结束，用 `update_current_span(cost=...)`（TypeScript 里是 `updateCurrentSpan`）上报。

<Tabs>
  <Tab title="Python">
    ```python
    from tavily import TavilyClient
    from traceroot import observe, update_current_span

    PRICE_PER_CREDIT = 0.008  # 你的套餐的每 credit 价格

    client = TavilyClient()  # 读取 TAVILY_API_KEY

    @observe(name="tavily_search", type="tool")
    def web_search(query: str):
        response = client.search(query, max_results=3, include_usage=True)
        credits = response.get("usage", {}).get("credits")
        if credits is not None:
            update_current_span(cost=credits * PRICE_PER_CREDIT)
        return response
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { tavily } from '@tavily/core';
    import { observe, updateCurrentSpan } from '@traceroot-ai/traceroot';

    const PRICE_PER_CREDIT = 0.008; // 你的套餐的每 credit 价格

    const client = tavily({ apiKey: process.env.TAVILY_API_KEY });

    async function webSearch(query: string) {
      return observe({ name: 'tavily_search', type: 'tool' }, async (q: string) => {
        const response = await client.search(q, { maxResults: 3, includeUsage: true });
        const credits = response.usage?.credits;
        if (credits !== undefined) updateCurrentSpan({ cost: credits * PRICE_PER_CREDIT });
        return response;
      }, query);
    }
    ```
  </Tab>
</Tabs>

像调用其他函数一样，在 agent 里调用 `web_search`。它的 span 会嵌套在调用它的 span 下面，它的成本会计入这条 trace 的总成本。

## 验证

运行你的代码，确认 trace 已经到达：
1. **在 traceroot 界面中**：进入 [traceroot Cloud](https://app.traceroot.ai) 的 **Tracing > Traces**。你会看到一个 `tavily_search` span，位于根部或你的 agent 的 span 下面。打开它可以看到成本，trace 的总成本里包含这笔成本。
2. **通过 CLI**：运行 `traceroot traces list`，在终端里查看最近的 trace。

## 采集的内容

| 属性 | 说明 |
|-----------|-------------|
| 输入 | 传给 `web_search` 的查询 |
| 输出 | 搜索响应 |
| 成本 | 消耗的 credit 数 × 你的每 credit 价格，单位是美元 |
| 延迟 | 请求耗时 |

## 限制

- 只有搜索请求了 usage 信息，Tavily 才会返回 credit 数；没有请求时，span 上不会记录成本。
- 把 `PRICE_PER_CREDIT` 设为你自己套餐的费率。
