自动采集所有通过 `google-genai` SDK 发起的 Gemini 模型调用。

## 安装

<Tabs>
  <Tab title="Python">
    ```bash
    pip install traceroot google-genai
    ```
  </Tab>
</Tabs>

## 设置

<Tabs>
  <Tab title="Python">
    ```python
    import traceroot
    from traceroot import Integration

    traceroot.initialize(integrations=[Integration.GOOGLE_GENAI])
    ```
  </Tab>
</Tabs>

## 使用

初始化之后，所有 Gemini 调用都会被自动采集，包括工具调用请求：

```python
import os
from google import genai
from google.genai import types

client = genai.Client(api_key=os.environ["GEMINI_API_KEY"])

weather_tool = types.Tool(function_declarations=[
    types.FunctionDeclaration(
        name="get_weather",
        description="Get current weather for a city",
        parameters=types.Schema(
            type="OBJECT",
            properties={"city": types.Schema(type="STRING", description="City name")},
            required=["city"],
        ),
    )
])

# 这次调用会被自动追踪
response = client.models.generate_content(
    model="gemini-3.8-flash",
    contents="What's the weather in Tokyo?",
    config=types.GenerateContentConfig(tools=[weather_tool]),
)

# 模型会请求调用 get_weather，你需要自己执行它并把结果发回去
print(response.function_calls)
```

## 验证

运行你的代码，确认 trace 已经到达：
1. **在 traceroot 界面中**：进入 [traceroot Cloud](https://app.traceroot.ai) 的 **Tracing > Traces**。你会看到一条根 span 为 `GenerateContent` 的 trace（流式调用时是 `GenerateContentStream`）。
2. **通过 CLI**：运行 `traceroot traces list`，在终端里查看最近的 trace。

## 采集的内容

| 属性 | 说明 |
|---|---|
| 模型 | `gemini-3.8-flash`、`gemini-3.5-flash-lite`、`gemini-3.1-pro-preview` 等 |
| 内容 | 输入的消息 |
| 响应 | 生成的文本和函数调用 |
| Token | 输入和输出的 token 数量 |
| 成本 | model ID 匹配 traceroot 价格表时计算得出 |
| 延迟 | 请求耗时 |

## 限制

- 把 Python 函数作为 `tools` 传入时，SDK 的自动函数调用会在一次 `generate_content` 调用里跑完整个工具循环。这样只会产生一个 span，成本也只按最后一次模型调用计算。想要每一步都有准确的 span 和成本，请传入函数声明，或者设置 `automatic_function_calling=types.AutomaticFunctionCallingConfig(disable=True)` 并手动运行循环。
