traceroot 通过自动插桩集成了主流的 LLM 提供商、agent 框架和 coding agent。每次调用都会被记录为一个 span，除了初始化之外不需要改动代码。

没找到你需要的集成？[到 GitHub 上提需求](https://github.com/traceroot-ai/traceroot/issues/new)。
