一次**评测**会用一个由用例组成的数据集运行你的系统，并为每个结果打分。

在 traceroot 里，每个用例都作为一条独立的 trace 运行，所以查看 eval 时，用的还是你在追踪里已经熟悉的 span 时间线、token 和成本视图。每个 scorer 产出一个指标，一次运行要按指标逐个来看，没有单一的总分。

SDK 提供 **Python** 和 **TypeScript** 两个版本，两者的 API 相同。

## 你需要写什么

- 一个**数据集**：要运行的用例，每个用例有一个 `input` 和一个可选的 `expected` 答案。
- 一个 **task**：被评测的系统，把 `input` 映射成 `output`。
- 一个或多个 **scorer**：把用例的结果变成指标的函数。

然后 `evaluate()` 会对每个用例运行 task，为每个结果打分，并上报这次运行。
