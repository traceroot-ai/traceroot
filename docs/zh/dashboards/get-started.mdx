---
title: 仪表盘快速上手
description: 把项目指标和 trace 列表整理成可复用的仪表盘
---

仪表盘让你用组件来探索项目的 trace 数据。你可以用它跟踪延迟、成本、token 用量和错误，也可以把 trace 列表放在指标旁边。

## 创建仪表盘

1. 在项目的导航里打开 **Dashboard**。
2. 点击 **New dashboard**，给它起个名字，也可以加一段描述。
3. 创建仪表盘，然后添加一个组件。

创建和编辑仪表盘或组件需要 MEMBER 或 ADMIN 权限。VIEWER 可以查看已有的仪表盘。详见[工作空间角色](/zh/getting-started/concepts#角色)。

## 构建组件

组件构建器会根据所选的数据视图提供字段和聚合方式。选择你想查看的指标，加上环境、模型等筛选条件；想比较不同分组时，再选择一个拆分维度。保存组件之前，先用预览检查结果。

选择一个包含你的应用流量的时间范围。仪表盘没有匹配的数据，和指标的值为零是两回事；如果组件没有结果，请检查时间范围和筛选条件。

随着监控需求的变化，你可以编辑已保存的组件。仪表盘属于当前项目，要查看另一个应用的仪表盘，请切换项目。要从脚本或 coding agent 里读取或修改它们，请使用 [CLI](/zh/cli/dashboards-and-widgets)。
