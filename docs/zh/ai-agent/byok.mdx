---
title: Bring Your Own Key (BYOK)
description: 用你自己的 LLM API key 驱动 traceroot Agent
---

默认情况下，traceroot 为 traceroot Agent 提供系统模型。通过 BYOK，你可以使用自己的 API key，自行决定用哪个模型。

## 默认模型

| 提供商 | 模型（第一个是默认模型） |
|----------|--------------------------------------|
| Anthropic | `claude-opus-4-8`, `claude-opus-4-7`, `claude-opus-4-6`, `claude-sonnet-5`, `claude-sonnet-5-5`, `claude-sonnet-4-6`, `claude-opus-4-5`, `claude-sonnet-4-5`, `claude-haiku-5-5`, `claude-haiku-4-5` |
| OpenAI | `gpt-5.5`, `gpt-6-luna`, `gpt-5.4`, `gpt-5.4-mini`, `gpt-5.4-nano`, `gpt-5`, `gpt-5-mini`, `o3`, `gpt-5.3-codex`, `gpt-5.6-sol`, `gpt-5.6-terra`, `gpt-6-sol` |

每个系统模型的说明见[支持的模型](/zh/integrations/internal-models)。

## 支持的提供商

OpenAI, Anthropic, DeepSeek, xAI, Moonshot (Kimi), Z.AI (GLM), Google Gemini, OpenRouter, Azure OpenAI, AWS Bedrock, TypeSafe AI.

**注意：** Azure OpenAI、AWS Bedrock 和 OpenRouter 没有预设的模型目录，可以直接填写任意模型 ID。

## 设置

1. 在仪表盘里进入 **Workspace Settings -> Model Providers**
2. 选择一个提供商
3. 输入你的 API key
4. 如果使用自托管或经过代理的模型，可以设置自定义 base URL
5. 保存。key 会加密存储，并且只在你的工作空间内有效

配置完成后，AI 对话界面的模型选择器会同时显示系统模型和你的 BYOK 模型。
