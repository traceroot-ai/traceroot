追踪会记录 AI agent 的所有行为，包括每一次 LLM 调用、工具调用和函数执行。你可以用它排查单次运行，也可以了解 agent 长期的表现。

启用追踪后，traceroot 会提供：
- **完整的 span 层级**：逐次调用地查看 agent 的执行过程
- **token 用量和成本**：既有每次 LLM 调用的数据，也有整条 trace 的汇总
- **源代码关联**：每个 span 都能对应到产生它的文件和代码行
