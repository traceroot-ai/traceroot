---
title: 数据采集与隐私
description: 了解并控制 traceroot 记录和导出的内容
---

traceroot 的 span 里可能包含应用数据。如果你要追踪的工作负载会处理个人数据、凭证或机密内容，请先了解默认行为。

## 默认采集的内容

| 数据 | 默认行为 | 如何限制 |
|---|---|---|
| 被 observe 的函数的参数 | 作为 span 输入采集 | 在 Python 里设置 `capture_input=False`，在 TypeScript 里设置 `captureInput: false` |
| 被 observe 的函数的返回值 | 作为 span 输出采集 | 在 Python 里设置 `capture_output=False`，在 TypeScript 里设置 `captureOutput: false` |
| 自动插桩的 LLM 提示词和 completion | 集成暴露内容时采集 | 用 [`redact`](#导出前脱敏个人数据) 改写或清空这些值；TypeScript 的 Pi 集成还提供内容过滤器（`captureContent`） |
| 工具的参数和结果 | 集成暴露工具 I/O 时采集 | 用 [`redact`](#导出前脱敏个人数据) 改写或清空这些值；TypeScript 的 Pi 集成还提供工具 I/O 采集选项（`captureToolIo: false`） |
| Git 仓库和 ref | 解析成功时作为 trace 级别的元数据 | 即使没有显式提供也会自动解析，git 上下文没有单独的关闭选项。要阻止导出，只能完全关闭追踪，详见 [Git 上下文](/zh/tracing/git-context) |
| 源文件、代码行和函数 | 由 `observe` / `@observe` 添加 | 如果源代码位置不能离开进程，请完全关闭追踪 |

采集设置会阻止选定的值写入 span。它不会改变你的应用传给 LLM 提供商或工具的内容。

## 关闭单个函数的输入和输出采集

<Tabs>
  <Tab title="Python">
    ```python
    from traceroot import observe

    @observe(capture_input=False, capture_output=False)
    def verify_password(username: str, password: str) -> bool:
        return check_credentials(username, password)
    ```
  </Tab>
  <Tab title="TypeScript">
    把函数的参数放在函数后面传入，`observe` 才能调用它。`captureInput: false` 会让这些参数不出现在 span 上：

    ```typescript
    import { observe } from '@traceroot-ai/traceroot';

    const authenticated = await observe(
      { name: 'verify_password', captureInput: false, captureOutput: false },
      verifyPassword,
      username,
      password,
    );
    ```
  </Tab>
</Tabs>

这些参数只作用于这次 `observe` 调用创建的 span。自动插桩的子调用仍然会按照各自集成的设置采集输入和输出。

## 导出前脱敏个人数据

需要 `traceroot` 0.4.0 或更高版本（Python），或 `@traceroot-ai/traceroot` 0.6.0 或更高版本（TypeScript；异步的 `redact` 需要 0.8.0）。

给 `initialize()` 传入一个 `redact` 函数。它会收到每个已结束 span 的属性，并返回要导出的内容，所以被它移除的内容不会到达 traceroot。下面的示例会清空邮箱地址和电话号码：

<Tabs>
  <Tab title="Python">
    ```python
    import re
    import traceroot

    PII = re.compile(r"[\w.+-]+@[\w-]+\.[\w.]+|(?<![\w-])(?:\+\d{1,3}[\s.-]?)?\(?\d{3}\)?[\s.-]?\d{3}[\s.-]?\d{4}(?![\w-])")

    def clean(value):
        if isinstance(value, str):
            return PII.sub("[REDACTED]", value)
        if isinstance(value, (list, tuple)):
            return [PII.sub("[REDACTED]", v) if isinstance(v, str) else v for v in value]
        return value

    def redact(attributes: dict) -> dict:
        return {key: clean(value) for key, value in attributes.items()}

    traceroot.initialize(redact=redact)
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { TraceRoot } from '@traceroot-ai/traceroot';

    const PII = /[\w.+-]+@[\w-]+\.[\w.]+|(?<![\w-])(?:\+\d{1,3}[\s.-]?)?\(?\d{3}\)?[\s.-]?\d{3}[\s.-]?\d{4}(?![\w-])/g;

    const clean = (value: string) => value.replace(PII, '[REDACTED]');

    TraceRoot.initialize({
      redact: (attributes) =>
        Object.fromEntries(
          Object.entries(attributes).map(([key, value]) => [
            key,
            typeof value === 'string'
              ? clean(value)
              : Array.isArray(value) && value.every((v): v is string => typeof v === 'string')
                ? value.map(clean)
                : value,
          ]),
        ),
    });
    ```
  </Tab>
</Tabs>

它的工作方式：

- 它在你的应用里运行，处理每一个已结束的 span，包括其他库产生的 span。在 Python 里，请保证它执行快、同步并且线程安全。在 TypeScript 里，它在导出时运行，不占用请求处理的时间，可以是异步函数；每个批次有 5 秒的时间。
- 它会收到 span 的内容：`observe` 的输入、输出和元数据，LLM 提示词，异常信息这类事件属性，以及状态信息。结构化的值会以 JSON 文本的形式传入，如果你的检测逻辑漏掉了 JSON 里的姓名，请先解析再处理。
- 它不会收到记录性质的字段：用户 ID 和会话 ID、模型名称和 token 用量、标签、环境、span 名称等。这些字段会原样发送，所以不要在里面放个人数据。用户 ID 请使用内部 ID，不要用邮箱地址。
- 请返回所有你想保留的 key。
- 只有 traceroot 收到的这一份会被改写。你的应用里的其他 exporter 拿到的仍然是原始 span。

<Warning>
如果这个函数抛出异常，或者返回的不是 dict（Python）或 object（TypeScript），元数据会被丢弃，除数字和布尔值之外的所有值都会以 `[redaction failed]` 发送。TypeScript 里的 promise 如果被 reject，或者 5 秒内没有完成，也按同样的方式处理。SDK 会输出一条警告日志。在 TypeScript 里，给 `initialize()` 传入 `logLevel: 'warn'` 才能看到它。
</Warning>

eval 的结果也会被脱敏。数据集和 scorer 的定义不会，所以不要在里面放个人数据。

正则表达式识别不了姓名和地址。要处理这些内容，请调用你自己运行的检测服务，例如在 [Presidio](https://microsoft.github.io/presidio/) 前面加一个轻量的服务。下面的示例把每个字符串发给一个接收并返回 `{ text }` 的服务：

```typescript
import { TraceRoot } from '@traceroot-ai/traceroot';

TraceRoot.initialize({
  redact: async (attributes) => {
    const detect = async (text: string): Promise<string> => {
      const response = await fetch(process.env.PII_SERVICE_URL!, {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ text }),
        signal: AbortSignal.timeout(4000),
      });
      if (!response.ok) throw new Error(`PII service returned ${response.status}`);
      return ((await response.json()) as { text: string }).text;
    };
    const entries = Object.entries(attributes).map(async ([key, value]) => [
      key,
      typeof value === 'string'
        ? await detect(value)
        : Array.isArray(value) && value.every((v): v is string => typeof v === 'string')
          ? await Promise.all(value.map(detect))
          : value,
    ]);
    return Object.fromEntries(await Promise.all(entries));
  },
});
```

<Note>
从 0.8.0 开始，TypeScript 的 `redact` 还会收到由 Vercel AI SDK 属性派生出来的 key（`input.value`、`output.value`、`llm.*`）。如果你丢弃了某些 `ai.*` key，请把这些 key 也一并丢弃。
</Note>

trace 视图会把这个函数处理过的每个 span 标记为 **已由你的应用脱敏**。

## 导出前脱敏 Pi 内容

TypeScript 的 Pi 插桩接受一个 `captureContent` 回调。它在内容附加到 span 之前运行，可以返回替换后的文本，也可以返回 `undefined` 来丢弃这一项。

```typescript
import * as pi from '@earendil-works/pi-coding-agent';
import { TraceRoot, type ContentCaptureFn } from '@traceroot-ai/traceroot';

const EMAIL = /[A-Z0-9._%+-]+@[A-Z0-9.-]+\.[A-Z]{2,}/gi;

const redactContent: ContentCaptureFn = (kind, value) => {
  if (kind === 'agent_input') {
    return value.text?.replace(EMAIL, '[redacted-email]');
  }

  // 不记录模型输入和响应正文。
  return undefined;
};

TraceRoot.initialize({
  instrumentModules: {
    piCodingAgent: {
      module: pi,
      config: {
        captureContent: redactContent,
        captureToolIo: false,
      },
    },
  },
});
```

回调这种形式只在 TypeScript 的 Pi 插桩里提供。其他集成和 Python 请使用上文的 [`redact`](#导出前脱敏个人数据)。

## 完全关闭追踪

在 SDK 初始化之前设置 `TRACEROOT_ENABLED`：

```bash
TRACEROOT_ENABLED=false
```

两个 SDK 接受的取值不同：

| SDK | 视为关闭的取值 |
|---|---|
| Python | `false`、`0`、`no` 或 `off`，不区分大小写 |
| TypeScript | 只接受小写字符串 `false` |

你也可以给 Python 的 `initialize()` 传入 `enabled=False`，或者给 TypeScript 的 `TraceRoot.initialize()` 传入 `enabled: false`。

## 隐私检查清单

- 在生产环境启用追踪之前，先对提示词、completion、函数参数、工具 I/O、元数据、标签和源代码路径做数据分级。
- 在尽量靠近处理敏感数据的函数或集成的位置关闭采集。
- 对于必须保留在采集内容里的部分，用 `redact` 去掉其中的个人数据。
- 不要把密钥放进元数据或手动的 span 更新里。
- 上线之前，先在非生产项目里检查一条有代表性的已导出 trace。
- 对你使用的 traceroot 部署，落实你所在组织的数据保留、访问控制和数据处理要求。
