TraceRoot is configured via environment variables. When running with Docker Compose, all configuration is centralized in a single `.env` file at the repository root.

---

## Required Secrets

Docker Compose checks secrets at load time using variable substitution syntax (`:?`). If any of the following three secrets are empty or unset, Compose will refuse to run:

| Variable | Description | How to Generate |
| :--- | :--- | :--- |
| **`BETTER_AUTH_SECRET`** | Secret key used by the `web` service to encrypt session tokens, cookies, and Better-Auth credentials. | `openssl rand -hex 32` |
| **`INTERNAL_API_SECRET`** | Shared HMAC secret used to authenticate inter-service communication between `web`, `rest`, `worker`, `billing`, `detector`, and `agent`. | `openssl rand -hex 32` |
| **`SQL_GATEWAY_BOOTSTRAP_PASSWORD`** | Password for the ClickHouse `sql_gateway_bootstrap` account. **Mandatory for all stacks**, because ClickHouse migrations run under this account. | `openssl rand -hex 32` |

<Note>
**Password Character Note**: Avoid unescaped ampersands (`&`) in ClickHouse passwords, as ClickHouse XML parser configuration may fail at container startup.
</Note>

## Critical Setting: `ENABLE_BILLING=false`

<Warning>
**Default Behavior in Compose**:
`docker-compose.prod.yml` defines the billing flag with a fallback to `true`:
```yaml
ENABLE_BILLING: ${ENABLE_BILLING:-true}
```
If you create a custom `.env` file and forget to include `ENABLE_BILLING`, Compose defaults it to **`true`**.

When `ENABLE_BILLING` is `true`:
- The REST API activates cloud rate limiting (`backend/rest/rate_limit.py`), throttling requests to plan quotas (e.g., 60 req/min).
- The web console enforces subscription seat and tier checks.
- Features require Stripe synchronization.

**For self-hosted deployments, always explicitly set:**
```bash .env
ENABLE_BILLING=false
```
Setting `ENABLE_BILLING=false` completely disables rate limiting, unlocks all features, and bypasses seat gates.
</Warning>

## Client Build-Time Variables (`NEXT_PUBLIC_*`)

Next.js inlines all variables prefixed with `NEXT_PUBLIC_` into the static JavaScript bundle **at build time**.

In `docker/Dockerfile.web`:
```dockerfile
ARG NEXT_PUBLIC_API_URL=/api/v1
ENV NEXT_PUBLIC_API_URL=${NEXT_PUBLIC_API_URL}
ARG NEXT_PUBLIC_APP_URL=http://localhost:3000
ENV NEXT_PUBLIC_APP_URL=${NEXT_PUBLIC_APP_URL}
```

<Important>
**Runtime Overrides Have No Effect**:
Setting `NEXT_PUBLIC_APP_URL` or `NEXT_PUBLIC_API_URL` under `environment:` in Docker Compose or at container runtime **does not affect client-side browser requests**.

If you are serving TraceRoot on a custom public domain or reverse proxy, you **must rebuild the `web` container** passing the build arguments:

```bash
docker compose -f docker-compose.prod.yml build \
  --build-arg NEXT_PUBLIC_APP_URL=https://traceroot.yourcompany.com \
  --build-arg NEXT_PUBLIC_API_URL=https://traceroot.yourcompany.com/api/v1 \
  web
```
</Important>

## Core Infrastructure Variables

| Variable | Default (Local Compose) | Description |
| :--- | :--- | :--- |
| `DATABASE_URL` | `postgresql://postgres:postgres@postgres:5432/postgres` | PostgreSQL connection string used by `web`, `rest`, `worker`, `detector`, and `agent`. |
| `CLICKHOUSE_HOST` | `clickhouse` | ClickHouse host address. |
| `CLICKHOUSE_PORT` | `8123` | ClickHouse HTTP interface port. |
| `CLICKHOUSE_NATIVE_PORT` | `9000` | ClickHouse TCP native protocol port (used for Goose migrations). |
| `CLICKHOUSE_USER` | `clickhouse` | Standard application database account. |
| `CLICKHOUSE_PASSWORD` | `clickhouse` | Password for application ClickHouse user. |
| `CLICKHOUSE_DATABASE` | `default` | ClickHouse database name. |
| `REDIS_URL` | `redis://redis:6379/0` | Primary Redis broker and cache. |
| `REDIS_RESULT_URL` | `redis://redis:6379/1` | Redis database for asynchronous Celery results. |
| `S3_ENDPOINT_URL` | `http://minio:9000` | S3-compatible object storage endpoint. |
| `S3_ACCESS_KEY_ID` | `minio` | S3 access key ID. |
| `S3_SECRET_ACCESS_KEY` | `minio-password` | S3 secret access key. |
| `S3_BUCKET_NAME` | `traceroot` | S3 bucket name. |
| `S3_REGION` | `us-east-1` | S3 AWS region. |

## AI Model Provider Keys

If you want the in-app AI assistant, automated root-cause analysis (RCA), or LLM-as-a-judge detectors to work, supply at least one LLM API key:

```bash .env
# Anthropic (Claude 3.5 Sonnet / Haiku)
ANTHROPIC_API_KEY=sk-ant-api03-...

# OpenAI (GPT-4o, GPT-4o-mini)
OPENAI_API_KEY=sk-proj-...
```

## Alerting & Detector Settings

The detector service executes both automated evals and the alerting engine:

| Variable | Default | Description |
| :--- | :--- | :--- |
| `ALERTS_SCHEDULER_ENABLED` | `true` | Controls the once-a-minute threshold evaluation tick in the `detector` service. Set to `false` to disable alert checks. |
| `DETECTOR_EVAL_TIMEOUT_MS` | `60000` | Per-attempt wall-clock timeout in milliseconds for LLM judge evaluation calls. |
| `TRACEROOT_SMTP_URL` | _None_ | SMTP connection URL (e.g. `smtp://user:pass@smtp.mailgun.org:587`) for alert notifications. |
| `TRACEROOT_SMTP_MAIL_FROM` | `noreply@traceroot.ai` | From address on outbound email notifications. |
