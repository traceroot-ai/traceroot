TraceRoot lets you organize analytical visualizations into custom dashboards composed of modular widgets. You can manage dashboard structures and query widget data directly through the CLI.

## Dashboards

### `traceroot dashboards list`

List all dashboards in your project.

```bash
traceroot dashboards list [options]
```

```bash
traceroot dashboards list
```

```text
DASHBOARD ID                           NAME                    WIDGETS  UPDATED
dsh_01a2b3c4d5e6f7a8b9c0d1e2f3a4b5c6   LLM Performance Overview 6        2026-10-01
dsh_98f7e6d5c4b3a2019283746554637281   Agent Cost & Errors     4        2026-09-28
```

---

### `traceroot dashboards get <id>`

Inspect a dashboard's metadata and the list of widgets it contains.

```bash
traceroot dashboards get <dashboard-id> [options]
```

```bash
traceroot dashboards get dsh_01a2b3c4d5e6f7a8b9c0d1e2f3a4b5c6
```

---

### `traceroot dashboards create`

Create a new dashboard.

```bash
traceroot dashboards create --from-file <path> [options]
```

#### Flags

| Flag | Type | Description |
| :--- | :--- | :--- |
| `--from-file <path>` | string | Path to JSON file (or `-` for stdin) |
| `--name <string>` | string | Name of the dashboard |
| `--description <string>` | string | Optional description |
| `--project <id>` | string | Project ID (required when using browser login) |

```bash
traceroot dashboards create --name "Production Agent Health" --description "Real-time metrics for customer support agents"
```

---

### `traceroot dashboards update <id>`

Rename a dashboard or update its description.

```bash
traceroot dashboards update <dashboard-id> [options]
```

```bash
traceroot dashboards update dsh_01a2b3c4d5e6f7a8b9c0d1e2f3a4b5c6 --name "Support Agent V2 Metrics"
```

---

### `traceroot dashboards delete <id>`

Permanently delete a dashboard and all widgets associated with it.

```bash
traceroot dashboards delete <dashboard-id> --reason <text>
```

#### Flags

| Flag | Type | Description |
| :--- | :--- | :--- |
| `--reason <text>` | string | *(Required)* Audit justification |

```bash
traceroot dashboards delete dsh_01a2b3c4d5e6f7a8b9c0d1e2f3a4b5c6 --reason "Superseded by global dashboard"
```

## Widgets

Widgets represent individual charts, counters, or tables anchored to a specific dashboard.

### `traceroot widgets create`

Add a new widget to an existing dashboard.

```bash
traceroot widgets create --from-file <path> [options]
```

#### Flags

| Flag | Type | Description |
| :--- | :--- | :--- |
| `--from-file <path>` | string | Path to JSON definition |
| `--dashboard-id <id>` | string | Target dashboard ID |
| `--title <string>` | string | Widget title |
| `--type <string>` | string | Widget type (`timeseries`, `counter`, `table`, `bar`) |
| `--spec <json-string>` | string | Query specification defining metrics, dimensions, and filters |

#### Example

Define a widget in `latency_widget.json`:

```json
{
  "dashboard_id": "dsh_01a2b3c4d5e6f7a8b9c0d1e2f3a4b5c6",
  "title": "P95 Latency by Model",
  "type": "timeseries",
  "spec": {
    "metric": "duration_ms",
    "aggregation": "p95",
    "group_by": ["model_name"]
  }
}
```

```bash
traceroot widgets create --from-file latency_widget.json
```

---

### `traceroot widgets get <id>`

Inspect a saved widget, including its title, type, and exact query specification.

```bash
traceroot widgets get <widget-id>
```

```bash
traceroot widgets get wdg_abcdef1234567890
```

---

### `traceroot widgets data <id>`

Execute a saved widget's query specification over a specific time window and print the computed results without re-sending the spec.

```bash
traceroot widgets data <widget-id> [options]
```

#### Flags

| Flag | Type | Description |
| :--- | :--- | :--- |
| `--range <preset>` | string | Time range preset (e.g. `1h`, `24h`, `7d`, `30d`) |
| `--start-time <iso>` | string | Custom window start timestamp |
| `--end-time <iso>` | string | Custom window end timestamp |
| `--json` | boolean | Output raw aggregated data points as JSON |

```bash
# Fetch widget data for the past 24 hours
traceroot widgets data wdg_abcdef1234567890 --range 24h
```

---

### `traceroot widgets update <id>`

Update a widget's title, query specification, or display settings.

```bash
traceroot widgets update <widget-id> [options]
```

<Warning>
Supplying `--spec` replaces the entire existing query specification.
</Warning>

```bash
traceroot widgets update wdg_abcdef1234567890 --title "Median & P95 Latency"
```

---

### `traceroot widgets delete <id>`

Permanently remove a widget from its dashboard.

```bash
traceroot widgets delete <widget-id> --reason <text>
```

```bash
traceroot widgets delete wdg_abcdef1234567890 --reason "No longer tracked"
```
