This page lists every command. A command with its own page has its flags there, and the rest list them here. `traceroot <command> --help` always has the full list.

## Global flags

Every command takes these.

| Flag | Effect |
| :- | :- |
| `--api-key <key>` | API key to authenticate with |
| `--host <url>` | API host |
| `--auth-host <url>` | Host for browser login and token exchange. Default: `--host` |
| `--project <id>` | Project for a browser login |
| `--env-file <path>` | `.env` file to load |
| `--json` | [Machine-readable output](/cli/scripting#json-output) |
| `--timeout <ms>` | Per-request timeout. Default: 30000 |
| `-V, --version` | Print the version |
| `-h, --help` | Print help |

[Authentication](/cli/authentication) covers how the credential, host, and project flags are resolved.

## Set up and diagnose

[Tracing](/tracing/get-started) covers what setup does.

| Command | What it does |
| :- | :- |
| `setup` | Connect this repository and see a first trace. Flags: `--agent <agent>`, `--language <language>`, `--service <path>`, `--project <name-or-id>`, `--handoff <code>`, `--no-browser`, `--no-instrument`, `--manual`, `--resume`, `--no-input`, `--trace-timeout <seconds>` |
| `setup doctor` | Diagnose a setup that didn't complete. Flag: `--service <path>` |
| `doctor` | Check credentials, traceroot files, the repository, the environment, and the skills `skills install` copies. Flag: `--service <path>` |
| `instrument` | Write a prompt for a coding agent to add traceroot, without editing your code. `setup` is the normal route. Flags: `--agent <agent>`, `--print`, `--output <path>`, `--force` |
| `skills list` | List the skills bundled with the CLI, and where they're installed |
| `skills install [skill]` | Copy `traceroot-instrument-repo` or `traceroot-quickstart` into an agent's skill directory. [Coding agents](/getting-started/coding-agents#skills) lists the skills to use. Flags: `--agent <agent>`, `--force`, `--dry-run` |
