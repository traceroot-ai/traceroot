This page provides a comprehensive reference for all global flags, environment variables, configuration files, and commands available in `traceroot-cli`.

## Global Flags

The following flags are available across all subcommands. Pass them before or after the command name.

| Flag | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `--api-key <key>` | string | — | Project API key (`tr_...`) for direct bearer authentication. |
| `--host <url>` | string | `https://app.traceroot.ai` | Target API backend URL. |
| `--auth-host <url>` | string | Value of `--host` | Auth host URL for browser device login and token minting (used in split dev environments). |
| `--project <id>` | string | — | Project ID to scope operations to (required for user credentials). |
| `--env-file <path>` | string | — | Path to an explicit `.env` file to load environment variables from. |
| `--json` | boolean | `false` | Emit machine-readable JSON output on stdout for supported commands. |
| `--timeout <ms>` | number | `30000` | Per-request network timeout in milliseconds. |
| `-h, --help` | boolean | — | Display help information for any command. |
| `-V, --version` | boolean | — | Display the CLI version. |

## Environment Variables

The CLI reads 12 environment variables to resolve configuration, credentials, paths, and output formatting.

| Variable | Default | Description |
| :--- | :--- | :--- |
| `TRACEROOT_API_KEY` | — | Project API key used for authentication. |
| `TRACEROOT_TOKEN` | — | Session token used for token-mint authentication. |
| `TRACEROOT_HOST_URL` | `https://app.traceroot.ai` | TraceRoot API server base URL. |
| `TRACEROOT_AUTH_URL` | Value of `TRACEROOT_HOST_URL` | Frontend URL for OAuth/device flow authentication. |
| `TRACEROOT_PROJECT_ID` | — | Default project ID used to scope user session requests. |
| `TRACEROOT_TIMEOUT_MS` | `30000` | Network request timeout in milliseconds. |
| `TRACEROOT_CONFIG_PATH` | `./.traceroot/config.json` | Path to the local project configuration file storing API keys. |
| `TRACEROOT_CREDENTIALS_PATH` | `~/.config/traceroot/credentials.json` | Path to the global user session credentials file. |
| `XDG_CONFIG_HOME` | `~/.config` | Base configuration directory (overrides default credential location). |
| `CODEX_HOME` | `~/.codex` | Base directory for Codex skill installations. |
| `NO_COLOR` | — | When set (to any value), suppresses all ANSI color and formatting codes. |
| `CI` | — | When set (e.g. by GitHub Actions, GitLab CI), disables interactive terminal prompts. |
