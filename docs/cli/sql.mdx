---
title: SQL Queries
description: Execute analytical SQL queries over spans and traces
---

The `traceroot sql` command allows you to execute read-only analytical SQL queries directly against your project's ClickHouse telemetry database. You can aggregate token costs, calculate percentiles, detect regressions, and export custom tabular data without leaving your terminal.

## Commands

### `traceroot sql [query]`

Run a single read-only `SELECT` query.

```bash
traceroot sql "<query>" [options]
```

#### Arguments

- `[query]`: The SQL query string. Must be enclosed in quotes. Alternatively, pass `--file <path>`.

#### Flags

| Flag | Type | Description |
| :--- | :--- | :--- |
| `--file <path>` | string | Read the SQL query from a file instead of a command-line argument |
| `--param <key=val>` | string | Bind values to `{key:Type}` parameters (repeatable) |
| `--max-rows <n>` | number | Maximum rows to return (capped by server limits) |
| `--csv` | boolean | Output results formatted as CSV (RFC 4180) |
| `--json` | boolean | Output full JSON object with columns, rows, and stats |
| `--output <file>` | string | Write output to a file instead of stdout |
| `--project <id>` | string | Project ID (required when using browser login) |

#### Output Formats

| Format | How to specify | Description |
| :--- | :--- | :--- |
| **Table** | Default | Formatted ASCII table. `NULL` values render as `NULL`. Total row counts and elapsed time go to stderr. |
| **CSV** | `--csv` | Comma-separated values adhering to RFC 4180. Nulls render as empty cells. Cannot be combined with `--json`. |
| **JSON** | `--json` | Single machine-readable JSON line containing: `columns`, `rows`, `row_count`, `truncated`, and `elapsed_ms`. |
| **File** | `--output <path>` | Writes any of the above formats to a file instead of stdout. |

#### Examples

```bash
# Count total spans captured over the last 24 hours
traceroot sql "SELECT count() AS spans FROM spans WHERE span_start_time >= now() - INTERVAL 1 DAY"

# Compute p95 latency grouped by model
traceroot sql "SELECT model_name, quantile(0.95)(duration_ms) AS p95_ms FROM spans WHERE model_name IS NOT NULL GROUP BY model_name ORDER BY p95_ms DESC"

# Calculate total token spend by model over the past 7 days
traceroot sql "SELECT model_name, sum(cost) AS total_cost FROM spans WHERE span_start_time >= now() - INTERVAL 7 DAY GROUP BY model_name ORDER BY total_cost DESC"

# Export recent error spans to CSV
traceroot sql "SELECT span_id, trace_id, name, status_message FROM spans WHERE status = 'ERROR' ORDER BY span_start_time DESC LIMIT 100" --csv --output errors.csv

# Parameterized query from a file
traceroot sql --file query.sql --param model=gpt-4o --max-rows 50
```

### `traceroot sql schema`

List the available tables and column definitions accessible in the analytical schema, along with their data types.

```bash
traceroot sql schema [options]
```

#### Flags

| Flag | Type | Description |
| :--- | :--- | :--- |
| `--json` | boolean | Emit the schema definition as JSON |
| `--project <id>` | string | Project ID (required when using browser login) |

```bash
traceroot sql schema
```

```text
TABLE: spans
COLUMN             TYPE         DESCRIPTION
span_id            String       Unique identifier for the span
trace_id           String       Parent trace identifier
name               String       Operation or span name
span_kind          String       INTERNAL, CLIENT, SERVER, AGENT, TOOL, LLM
span_start_time    DateTime64   Start timestamp (UTC)
span_end_time      DateTime64   End timestamp (UTC)
duration_ms        Float64      Duration in milliseconds
status             String       OK, ERROR, UNSET
status_message     String       Error description when status is ERROR
model_name         String       Underlying LLM model identifier
input_tokens       UInt32       Prompt/input token count
output_tokens      UInt32       Completion token count
cost               Float64      Estimated cost in USD
service_name       String       Instrumented service or application name

TABLE: traces
COLUMN             TYPE         DESCRIPTION
trace_id           String       Unique identifier for the trace
root_span_name     String       Name of the root span
trace_start_time   DateTime64   Start timestamp of the root span (UTC)
trace_end_time     DateTime64   End timestamp of the final child span (UTC)
duration_ms        Float64      Total trace duration in milliseconds
status             String       Overall status of the trace
total_spans        UInt32       Number of spans in the trace
total_cost         Float64      Total aggregated token cost in USD
```

<Note>
**Data Privacy & Analytical Focus**

To protect privacy and ensure query speed, raw input/output payloads and prompt strings are not indexed in the analytical SQL schema. Use `traceroot traces get <id> --fields full` or `traceroot traces export` to inspect complete payloads.
</Note>
