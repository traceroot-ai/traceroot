Alerts are delivered to **Slack only**. There is no email delivery for alerts. Slack delivery is available on every plan, including Free.

Alerts post to the Slack channel connected to your TraceRoot workspace. The integration is workspace-level: one Slack workspace per TraceRoot workspace, with a destination channel you pick in workspace settings. [Detector notifications](/detectors/notifications) use the same connection.

## Connect Slack

1. Open **Settings** then **Integrations** as a workspace admin.
2. Click **Connect** and complete the OAuth flow in your Slack workspace.
3. Pick the channel TraceRoot should post to.

The alert form and the Alerts onboarding page both show the connected workspace and channel, and link to these settings.

<Note>
  A rule can be created before Slack is connected. If it breaches in that state, the notification is recorded as not delivered. Once you connect Slack or choose a channel, TraceRoot sends that notification on the rule's next evaluation, as long as the rule is still in the same state.
</Note>

## What a message contains

Every message has a header with the new severity and the rule's name, such as `[ALERT] p95 LLM latency above 2s`.

A breach, recovery or no-data message also has:

- One sentence stating the measured value, the threshold and the window, followed by the rule's filters.
- The evaluated time range in UTC and the transition, such as `OK to ALERT`.

The links depend on the kind of message:

| Message | When it is sent | Links |
| --- | --- | --- |
| Breach (`ALERT`) | The rule enters **Alert**, and on each renotify interval while it stays there | **View alert**, **View traces** |
| Recovery (`OK`) | A rule that had announced a breach returns within its threshold | **View alert** |
| No data (`NO_DATA`) | Only under **Notify when data stops**, once the gap has lasted long enough | **View alert** |
| Closed (`OK`) | A rule with an open alert is edited or resumed, which starts it fresh | **View alert** |

A closed message is not a recovery. It carries no measured value: it names who edited or resumed the rule and says the previous alert is closed. If the metric still breaches, a new `[ALERT]` follows it from the next evaluation. A rule edited while paused still sends its closed message, because the alert it closes was already announced.

**View alert** opens the rule. **View traces** opens the trace list over the evaluated time window.

### What View traces shows

The trace list can be broader than the spans the rule counted:

- The alert evaluates spans, while the list shows traces that contain at least one matching span.
- The link carries `=` filters on model, environment, status, span kind and span name, and metadata filters. A `contains` filter on those fields and an `is_root` filter are not applied to the list.

The sentence in the message always lists every filter on the rule, so read it for the exact conditions.

## When a notification is not delivered

If Slack is briefly unavailable or rate limits the request, TraceRoot retries for about 30 minutes. If the message still cannot be sent, the alert is rolled back so the next evaluation raises it again.

Other failures need a change on your side. Click the rule's badge in the Alerts list to see the reason:

| Reason shown | Fix |
| --- | --- |
| No Slack channel is set for this workspace | Choose a channel under **Settings → Integrations**. The notification is sent on the next evaluation. |
| This workspace's Slack connection is incomplete | Reconnect Slack under **Settings → Integrations**. The notification is sent on the next evaluation. |
| Slack rejected the message | Check that the channel still exists and that the TraceRoot app is still in it. This notification is not sent again; the rule notifies on its next change of state. |

A notification is never sent for a rule that was paused or deleted while the message was waiting to be delivered. A closed message is the exception for a paused rule: it is still sent.

A closed message that Slack keeps refusing for about 30 minutes is queued again on the next evaluation. One that cannot be delivered because no channel is set, the Slack connection is incomplete, or Slack rejected it is not sent again.
