The TraceRoot AI agent is accessible as a first-class project section via the **Home** item in the sidebar (`/projects/{projectId}/home`).

Home provides a full-page workspace where you can query telemetry, analyze error trends, investigate root causes, and manage project configurations in natural language.

## Starter Prompts

While a session has no messages, Home offers three starter prompts:

- *"Investigate the most recent errored trace"*
- *"Summarize today's sessions"*
- *"What did detector findings flag this week?"*

These are plain text. Clicking one sends it through the same path as the message input, so the agent answers it as it would the same question typed by hand. You can also type free-form queries in the input box.

---

## Persistent Conversations Across Navigation

Chat state in TraceRoot is managed through an application-wide provider (`AiChatProvider`):

- **Survives page navigation**: A conversation started on the Home page remains active as you navigate to other sections of the project (such as Traces, Dashboards, Detectors, or Alerts).
- **Assistant Drawer**: When leaving the Home page, the conversation remains available in the right-rail assistant drawer when you open it, letting you reference chat findings while viewing dashboard charts or inspecting trace trees.
- **Project Scoping**: Conversations are scoped to your active project, automatically binding project credentials and context to every tool call.

---

## Chat History & Stored Sessions

Every conversation is persisted in the database as an AI session (`AISession`):

- **Session History**: You can review past debugging trajectories, tool invocations, and answers across previous sessions.
- **One Pending Action per Session**: To ensure safety, each session can have at most one pending approval card at a time.
- **Turn-Level Trace Links**: For full observability, each assistant reply includes a **View trace** button (when the trace is available or uploading). Clicking it opens the trace of that specific turn, showing exact model prompts, tool arguments, latency, and token consumption.
