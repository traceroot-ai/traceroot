---
title: Bring Your Own Key (BYOK)
description: Use your own LLM API keys to power the TraceRoot AI agent
---

By default, TraceRoot provides system models for the AI agent. With BYOK, you can bring your own API keys to control which model is used.

## Default Models

| Provider | Models (first entry is the default) |
|----------|--------------------------------------|
| Anthropic | `claude-opus-4-8`, `claude-opus-4-7`, `claude-opus-4-6`, `claude-sonnet-5`, `claude-sonnet-4-6`, `claude-opus-4-5`, `claude-sonnet-4-5`, `claude-haiku-4-5` |
| OpenAI | `gpt-5.5`, `gpt-5.4`, `gpt-5.4-mini`, `gpt-5.4-nano`, `gpt-5`, `gpt-5-mini`, `o3`, `o4-mini`, `gpt-5.3-codex` |

See [Supported Models](/integrations/internal-models) for a description of each system model.

## Supported Providers

OpenAI, Anthropic, DeepSeek, xAI, Moonshot (Kimi), Z.AI (GLM), Google Gemini, OpenRouter, Azure OpenAI, AWS Bedrock, TypeSafe AI.

## Setup

1. Go to Workspace Settings -> Model Providers in the dashboard
2. Select a provider
3. Enter your API key
4. Optionally set a custom base URL for self-hosted or proxied models
5. Save — keys are encrypted at rest and scoped to your workspace

Once configured, the model selector in the AI chat interface will show both system models and your BYOK models.
