title: Bring Your Own Key (BYOK)
description: Use your own LLM API keys to power the TraceRoot AI agent
---

By default, TraceRoot provides system models for the AI agent. With BYOK, you can bring your own API keys to control which model is used.

## Supported Providers

OpenAI, Anthropic, Azure OpenAI, Google (Gemini), Amazon Bedrock, xAI, DeepSeek, OpenRouter, Kimi, GLM.

## BYOK Models

Your own key unlocks models beyond the system list above — typically newer frontier
models, or models TraceRoot does not run on its own keys.

Which models those are depends on the provider you configure, and the set changes as
providers ship new models, so it is not reproduced here. Add a key and open the model
selector in the AI chat interface to see everything available to your workspace.

## Setup

1. Go to Workspace Settings -> Model Providers in the dashboard
2. Select a provider
3. Enter your API key
4. Optionally set a custom base URL for self-hosted or proxied models
5. Save — keys are encrypted at rest and scoped to your workspace

Once configured, the model selector in the AI chat interface lists both the system models above and every model your key makes available.
